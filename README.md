# Death Count
This Death Counter mod uses Statistics to update the leaderboard

# Commands
**/deaths** - shows your own Deaths <br>
**/deaths <player>** - shows a Player's Deaths <br>
**/deaths list** - lists the Leaderboard of Deaths <br>
**/deaths reload** - players with OP can reload the Death Count <br>

# Config
**leaderboardSize** (default: 10) - how many players show on the Leaderboard <br>
**operatorLevel** (default: 4) - permission level to reload the Leaderboard
